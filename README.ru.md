# Remove-Paths — интерактивное удаление файлов и каталогов

Windows 10/11, Windows PowerShell 5.1 (x86/x64).

## Запуск

Распакуйте архив целиком, не изменяя структуру каталогов. Запустите
`Remove-Paths.ps1` из PowerShell или через «Выполнить с помощью PowerShell»
в Проводнике. Обязательных параметров нет.

```powershell
.\Remove-Paths.ps1
```

Общая библиотека `Common/Utility.ps1` проверяет права администратора, выбирает
язык по `Get-UICulture`, загружает PSD1 и выводит заголовок. При необходимости
через UAC перезапускается **сама утилита**, а не библиотека. Если повышение
прав отклонено, исходный запуск заканчивается без удаления, сводки и паузы.

Для явного выбора файла языка:

```powershell
.\Remove-Paths.ps1 -LanguageFile 'ru.psd1'
.\Remove-Paths.ps1 -LanguageFile 'D:\Locales\ru.psd1'
```

По умолчанию ищется файл с полным именем языка интерфейса Windows, затем
сокращённым именем, затем обязательный `en.psd1`: `ru-RU.psd1` → `ru.psd1` →
`en.psd1`. Поставляются русский и английский переводы. Загружается ровно
один PSD1. Если явно указанный файл отсутствует, это ошибка.

При запуске из Проводника и при новом окне после UAC в конце выводится
предложение нажать клавишу. При запуске в уже открытом терминале паузы нет.
Режим определяется с помощью родительского процесса, а при UAC явно
передаётся `-PauseOnExit`.

## Удаление

Вводите абсолютные пути, по одному в строке; пустой Enter завершает ввод.
Затем проверьте сводку и подтвердите `Y` или отмените `N`. Значения по
умолчанию нет. Удаление происходит без корзины.

Если обычное удаление невозможно, скрипт пробует сменить владельца на
«Администраторы», включить наследование и назначить полный доступ группе
«Все» (SID `S-1-1-0`). Нет рекурсивных `takeown /R` и `icacls /T`.

Для NTFS junction, symlink и точек монтирования удаляется только сама ссылка.
Содержимое и права её цели не изменяются. Операции с правами выполняются
только для реальных объектов, каталог за каталогом.

Защищены корни дисков, `C:\Users` со всеми подпапками и другие важные
системные пути диска C и диска работающей Windows. Не принимаются пути
через SUBST или промежуточные NTFS-ссылки.

После выполнения, отмены `N`, ошибки или обычного `Ctrl+C` скрипт старается
вывести итоговую сводку в `finally`; принудительное завершение процесса не
позволяет гарантировать её вывод.

## Общие функции

Жизненный цикл устроен через `Start-Utility` и `Stop-Utility`.
См. `Common/UTILITY-CONTRACT.ru.md` — единый контракт для будущих утилит.
