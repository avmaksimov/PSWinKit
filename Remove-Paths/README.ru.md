# Remove-Paths — безвозвратное удаление файлов и каталогов

[English](README.md) | **Русский**

Интерактивная утилита для удаления выбранных файлов и папок, в том числе со сложными NTFS-разрешениями, атрибутами «только чтение» и длинными путями.

**Внимание: удаляет напрямую, без корзины. Операция необратима штатными средствами Windows.** Проверяйте введённые пути перед подтверждением.

## Требования и запуск

Windows 10+, Windows Server 2016+, Windows PowerShell 5.1, x86/x64, где применимо. Для удаления требуются повышенные права администратора; при необходимости `Common/Common.ps1` запрашивает UAC. PowerShell 7 и сторонние модули не нужны.

Из корня PSWinKit:

```powershell
.\Remove-Paths\Remove-Paths.ps1
```

Из каталога `Remove-Paths`:

```powershell
.\Remove-Paths.ps1
```

Обязательных и специальных параметров командной строки нет. Язык интерфейса определяется по `Get-UICulture` (точный код → основной язык → английский), а дата, время и разделитель длительности — по региональным настройкам Windows. После UAC выполняется заново сам основной скрипт; отмена UAC не приводит к удалению и сводке.

## Порядок работы

1. Предупреждение о безвозвратном удалении появляется **до** первого ввода пути.
2. Введите по одному абсолютному пути: `1. Путь:`, `2. Путь:` и т. д. **Пустой Enter** завершает список.
3. Утилита проверит список, исключит повторы, перекрывающиеся и защищённые пути; сообщит количество выбранных и пропущенных целей.
4. Подтвердите операцию `Y` или откажитесь `N`: значения по умолчанию нет.
5. Удаление идёт последовательно с исходными номерами, живыми счётчиками и длительностью **каждого** пути.
6. В конце показываются результат, только не полностью удалённые пути, сводные числа и общее время выполнения.

В процессе отображается одна обновляемая строка состояния: счётчики файлов, каталогов и ошибок либо текущий путь при обходе, назначении прав и смене владельца. Обновление происходит периодически, обычно раз в 5 секунд. Окончательные ошибки выводятся отдельными серыми строками в формате `Не удалось удалить [причина]: путь`.

## Безопасность и особенности удаления

- Нельзя выбирать корни дисков, `C:\Users` и другие защищённые системные пути на C: и системном диске работающей Windows. Не поддерживаются SUBST, промежуточные NTFS-ссылки и неоднозначные короткие имена 8.3.
- При обходе **не происходит переходов в цели** symbolic link, junction и точек монтирования NTFS: удаляется только сама ссылка. ACL и владельцы целевых объектов не меняются.
- Используются Windows Authz для проверки фактических прав при обходе настоящих каталогов. При недостатке прав сначала пробуется назначение ACL **только текущему объекту**. Смена владельца выполняется лишь при неуспехе изменения ACL. Нет рекурсивных `takeown /R`, `icacls /T` и принудительного изменения наследования.
- Для длинных путей используются расширенные пути Windows (`\\?\...`). Файлы удаляются с `Remove-Item -Force`, пустые обычные каталоги — через .NET; при необходимости с каталога снимается `ReadOnly` и удаление повторяется.
- Ошибки не считаются окончательными, пока попытки восстановления доступа не исчерпаны. При обычном `Ctrl+C` итог выводится по возможности; при принудительном завершении процесса сводка не гарантируется.
- В итоговом числе файлов учитываются только обычные файлы внутри **полностью удалённых** путей. Каталоги, ссылки и файлы из частично удалённых путей не входят в этот показатель.

Общий таймер запускается после успешной проверки/повышения прав в `Start-Utility`, до вывода заголовка и основной логики, и заканчивается в `Stop-Utility`. Таймеры отдельных удаляемых путей независимы; общее время **не является их суммой**. Даты, время и длительности форматируются регионально; дни при необходимости обозначаются локализованно (`д` / `d`).

## Структура и сопровождение

- `Remove-Paths.ps1` — основная утилита, собственная логика удаления.

Файлы `.ps1` и `.psd1` сохраняются в UTF-8 с BOM для Windows PowerShell 5.1. Не копируйте Common внутрь папки утилиты.
